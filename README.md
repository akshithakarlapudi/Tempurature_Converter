# Temperature Converter 🌡️

## About the Project
The Temperature Converter is a simple and responsive web application developed using HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin easily.

## Features
- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Simple and user-friendly interface.
- Input validation to prevent invalid temperature values.
- Responsive design for different screen sizes.

## Technologies Used
- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Temperature conversion logic and validation.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a temperature value.
5. Select the input temperature unit.
6. Click the Convert button to view the results.

## Temperature Conversion Formulas
- Celsius to Fahrenheit: `(C × 9/5) + 32`
- Celsius to Kelvin: `C + 273.15`
- Fahrenheit to Celsius: `(F − 32) × 5/9`
- Kelvin to Celsius: `K − 273.15`
